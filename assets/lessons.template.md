# Trading lessons

Read at the start of every session. Only `confirmed` lessons change behaviour on their own; `hypothesis` lessons are mentioned, not obeyed. Lessons that would increase risk need the user's OK.

Format:
```
### L<n> — <one-line rule>
- Status: hypothesis | confirmed | retired
- Applies to: <market / asset / horizon / setup>
- Evidence for: <trade IDs, backtests, history examples>
- Evidence against: <...>
- Count: <for>–<against>
- Last reviewed: <YYYY-MM-DD>
```
